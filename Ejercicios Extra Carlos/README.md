# Material de Repaso

En esta carpeta encontraréis enunciados y ejercicios con soluciones adicionales de repaso de los diferentes módulos de la formación.

## Objetivo

El objetivo de este material es afianzar conceptos, ganar soltura con Python y seguir practicando de manera progresiva.

## Contenido

Aquí se irán incorporando materiales complementarios para reforzar los conocimientos adquiridos durante el curso:
- Ejercicios prácticos de repaso  
- Enunciados propuestos para practicar  
- Soluciones 

## Recomendaciones

Se recomienda realizar primero los ejercicios de forma autónoma y consultar las soluciones posteriormente para comprobar el proceso seguido.
